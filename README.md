# Taller de Motos - Gestión

Aplicación web simple para gestionar:

- clientes
- vehículos
- cotizaciones
- ingresos
- resumen del taller

## Cómo usar

1. Abre la carpeta del proyecto.
2. Ejecuta un servidor local desde la raíz:

```bash
python -m http.server 8000
```

3. Abre en el navegador:

```text
http://localhost:8000
```

## Funcionalidades

- Dashboard con métricas generales
- Registro de clientes y vehículos
- Cotizaciones con estado
- Registro de ingresos por servicio
- Persistencia en navegador con localStorage

## Tecnologías

- HTML
- CSS
- JavaScript puro
